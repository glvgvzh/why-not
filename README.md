# WhyNot

WhyNot - мобильное приложение с ежедневными мини-квестами, которые помогают разнообразить рутину и попробовать что-то новое.

Каждый день приложение предлагает один квест. Его можно выполнить или заменить, а завершённые и пропущенные дни сохраняются в истории.

## Возможности

- ежедневный квест
- выполнение и замена квеста
- ограничение количества замен до одного раза в день
- история выполненных и пропущенных квестов
- автоматическое добавление пропущенных дней
- сохранение состояния между перезапусками приложения
- обновление ежедневного квеста при смене дня
- корректное обновление состояния после возврата приложения из фона

## Технологии

- React Native
- Expo
- TypeScript
- AsyncStorage
- Jest
- React Native Testing Library

## Установка и запуск

1. Клонировать репозиторий.
2. Установить зависимости:

```bash
npm install
```

3. Запустить проект:

```bash
npx expo start
```

После запуска приложение можно открыть в iOS Simulator или Expo Go.

## Проверка проекта

Запустить тесты:

```bash
npm test
```

Проверить TypeScript:

```bash
npx tsc --noEmit
```
